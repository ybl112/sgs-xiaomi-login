# 三国杀一将成名 · 小米服登录

在三国杀官网通过小米官方授权登录小米渠道服的油猴脚本，支持账号管理、独立游戏窗口和登录面板操作。

**当前版本：0.2.6** · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/ybl112/sgs-xiaomi-login/issues)

## 安装

1. 在浏览器中安装并启用 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 点击 **[安装／更新脚本](https://raw.githubusercontent.com/ybl112/sgs-xiaomi-login/main/三国杀小米服登录.user.js)**，在油猴确认页点击“安装”或“更新”。
3. 打开 [三国杀一将成名官网登录页](https://web.sanguosha.com/login/10th_client/index.html)，右上角会出现“小米服”面板，底部版本号应为 **0.2.6**。

如果点击后只显示脚本源码，请确认当前浏览器已启用油猴；也可以进入油猴管理面板，新建脚本，将本仓库的 [脚本源码](三国杀小米服登录.user.js) 完整复制进去并保存。安装方式见 [油猴官方说明](https://www.tampermonkey.net/faq.php#Q102)。

## 登录

1. 在“小米服”面板选择 **登录方式一** 或 **登录方式二**。
2. 在弹出的官方页面自行完成登录和授权。
3. 授权完成后，脚本会继续取得游戏会话并接入小米服。

| 入口 | 使用方式 |
| --- | --- |
| 登录方式一 | 原小米官方游戏授权页，沿用之前的登录流程 |
| 登录方式二 | 先打开小米官方标准登录页，可选择微信等方式，登录后自动继续游戏授权 |

使用微信登录时，选择 **登录方式二**，在官方页面下方找到微信图标，用微信扫码完成登录。小米官方的第三方登录说明见 [帮助中心](https://account.xiaomi.com/helpcenter/faq/zh_CN/01.guide/02.login/faq-2)。如果已登录了其他小米账号，请先使用 **切换小米账号** 换号，再重新选择登录入口。

密码和验证码只需在官方页面输入，脚本面板无需填写。

| 功能 | 说明 |

## 账号管理

### 添加账号

点击 **添加账号（新窗口）**，在新窗口中选择登录方式，完成小米官方授权。需要添加其他账号时，使用 **切换小米账号** 打开小米官方账号页，自行换号后返回对应游戏窗口授权。

同一浏览器的小米官方授权页共享登录状态。每次授权前，请确认使用的是目标账号；账号列表保存的是管理记录，进入游戏仍需完成授权。

### 打开、备注与移除

在 **账号管理** 列表中选中目标账号，再选择操作：

- **打开账号窗口／返回已有窗口**：打开对应账号入口，或定位已打开的游戏窗口。
- **修改备注**：编辑账号备注及区服备注。
- **移除记录**：删除本机保存的管理记录，不删除游戏角色，也不会关闭已打开的游戏。
- **查看账号信息**：显示已取得的账号和角色标识，支持复制。旧记录缺少字段时，使用新版重新授权一次即可尝试补全。

账号信息中的 `appAccountId`、`account` 等字段用于标识登录接入账号，不等同于绑定手机号或官网账号密码，也不保证能用于官网密码找回。

### 返回原窗口与重新登录

脚本会请求同账号的其他窗口回应，辅助判断是否已有活动窗口。需要重新登录时，可以点击 **仍在此窗口登录** 并再次授权；服务器可能使原窗口下线。

浏览器可能限制窗口自动切换焦点。如果没有切到目标窗口，请手动切换浏览器窗口或标签页。

## 面板操作

- **移动**：按住面板标题拖动。
- **隐藏**：点击“隐藏”。
- **恢复**：从油猴菜单选择 **小米服：显示登录面板**。
- **重置位置**：从油猴菜单选择 **小米服：重置面板位置**。

每次重新打开或刷新页面，面板都会恢复为右上角显示、展开的状态；隐藏和拖动只影响当前页面。账号列表会保留。

## 常见问题

### 安装后没有出现面板

确认脚本已启用、当前页面是上面的官网登录页，并检查油猴的网站访问权限。浏览器如要求启用用户脚本权限，可参考 [油猴官方权限说明](https://www.tampermonkey.net/faq.php#Q209)，设置完成后刷新页面。

### 授权窗口或账号窗口没有打开

请允许三国杀官网弹出窗口，再重新操作。

### 授权后停在空白页或 404 页面

回到原游戏窗口，展开 **授权后卡在 404／空白页？**，将授权窗口的完整地址粘贴到输入框，再点击 **继续登录**。该地址包含一次性授权信息，只需粘贴到脚本面板，不要公开发送。

### 提示授权账号与所选账号不一致

点击“切换小米账号”，在官方页面换成列表中所选账号，再回到对应游戏窗口重新授权。

### 提示其他游戏窗口仍有响应，但需要在当前窗口登录

点击 **仍在此窗口登录**，重新完成同一账号的小米官方授权。

### 更新脚本

- 打开或刷新游戏页面时自动检查更新；检查结果缓存六小时，页面长时间打开时也会定时检查。
- 发现新版会直接打开油猴更新页，不弹出额外提示。同一个新版本只自动打开一次，避免多窗口或刷新反复开页；在油猴页面确认更新后，刷新游戏页即可使用新版。
- 面板底部保留 **检查更新** 按钮，点击后立即重新检查。有新版时直接打开更新页；已是最新版或检查失败时，会在面板状态中显示结果。手动检查可再次打开之前关闭的新版更新页。
- 若检查时正在进行登录授权，会等本次流程结束再打开更新页。后台网络失败不会弹提示或影响游戏登录。
- 脚本也配置了油猴的更新地址，油猴自身是否自动安装更新取决于其设置。相关字段见 [油猴官方文档](https://www.tampermonkey.net/documentation.php?locale=en&q=update_url)。

旧版用户需要先通过上面的 **安装／更新脚本** 链接更新至 **0.2.6**，之后即可使用自动检查功能。更新记录见 [CHANGELOG.md](CHANGELOG.md)。

### 如何反馈问题

在面板中展开 **查看状态记录**，点击 **导出诊断**。到 [Issues](https://github.com/ybl112/sgs-xiaomi-login/issues) 提交浏览器名称、脚本版本、操作步骤和最后一条状态；需要时附上诊断文件。

反馈时请勿公开密码、验证码、完整授权地址或登录凭据；截图如包含个人账号信息，请先遮挡。

## 数据说明

- 账号备注、账号标识、昵称、角色信息和时间等管理记录保存在本机油猴存储中，可通过账号列表移除。
- 管理记录不保存密码、token、ticket 或游戏会话；账号信息中的数字标识本身不能替代登录授权。
- 授权码通过油猴存储临时交接，启动参数通过当前窗口的 `sessionStorage` 一次性交接，读取后清理，并校验有效期。
- 必要的登录字段发送至小米和游卡官方接口；脚本没有上传账号管理记录的第三方服务。
- 更新检查从 GitHub 读取公开脚本，不发送账号、角色信息或授权凭据。
- 油猴菜单中的 **小米服：清除临时授权记录** 用于清理临时交接数据；游戏内退出请使用游戏自带功能。

本项目是非官方的浏览器辅助脚本，适用于小米渠道的《三国杀一将成名》。
