# 三国杀一将成名 · 小米服登录

在三国杀官网通过小米官方授权登录小米渠道服的油猴脚本，支持保存各账号登录凭据、选号登录、独立游戏窗口和登录面板操作。

**当前版本：0.3.0** · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/ybl112/sgs-xiaomi-login/issues)

## 安装

1. 在浏览器中安装并启用 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 点击 **[安装／更新脚本](https://raw.githubusercontent.com/ybl112/sgs-xiaomi-login/main/三国杀小米服登录.user.js)**，在油猴确认页点击“安装”或“更新”。
3. 打开 [三国杀一将成名官网登录页](https://web.sanguosha.com/login/10th_client/index.html)，右上角会出现“小米服”面板，底部版本号应为 **0.3.0**。

如果点击后只显示脚本源码，请确认当前浏览器已启用油猴；也可以进入油猴管理面板，新建脚本，将本仓库的 [脚本源码](三国杀小米服登录.user.js) 完整复制进去并保存。安装方式见 [油猴官方说明](https://www.tampermonkey.net/faq.php#Q102)。

## 登录

1. 在“小米服”面板选择 **登录方式一** 或 **登录方式二**。
2. 在弹出的官方页面自行完成登录和授权。
3. 授权完成后，脚本会继续取得游戏会话并接入小米服。

| 入口 | 使用方式 |
| --- | --- |
| 登录方式一 | 原小米官方游戏授权页，沿用之前的登录流程 |
| 登录方式二 | 先打开小米官方标准登录页，可选择微信等方式，登录后自动继续游戏授权 |

使用微信登录时，选择 **登录方式二**，在官方页面下方找到微信图标，用微信扫码完成登录。小米官方的第三方登录说明见 [帮助中心](https://account.xiaomi.com/helpcenter/faq/zh_CN/01.guide/02.login/faq-2)。要添加其他账号，请在 **账号管理** 中点击 **添加账号**，新账号会单独保存凭据。

密码和验证码只需在官方页面输入，脚本面板无需填写。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 小米官方授权登录 | 在官网登录页接入小米渠道服账号 |

| 备注管理 | 在账号列表中选择账号，统一修改备注或移除记录 |
| 账号信息 | 查看并复制小米游戏账号标识、游戏接入账号和已取得的角色信息 |

## 账号管理

账号管理默认收起，标题显示本机保存的账号数量。点击 **账号管理** 展开列表和操作；每次打开或刷新页面都会恢复收起状态。

### 添加账号与保存凭据

1. 选择 **标准登录（含微信）** 或 **账号密码登录**，点击 **添加账号**。
2. 脚本直接打开小米官方登录窗口。登录并完成授权后，账号和该账号的小米游戏会话保存在本机油猴存储中。
3. 添加只保存账号及凭据，不打开三国杀官网新窗口、不自动进入游戏、不执行小米网页退出，也不更换当前游戏窗口的账号。

普通浏览器窗口共享小米网站登录状态；添加会单独初始化官方登录表单，供输入要添加的账号。成功添加后的游戏接入使用各账号分别保存的会话，不依赖小米网页当前登录的是哪个账号。

旧版保存的账号备注和角色记录继续保留。选中旧账号，在 **账号详情与授权** 中点击 **重新授权** 一次，即可保存该账号的凭据。重新授权会核对账号，防止覆盖其他账号。

### 选择账号进入游戏

账号以卡片显示，标明“凭据已保存”“需要授权”或“游戏中”。点击卡片选中账号，再点击 **登录所选账号**，脚本使用该账号的会话申请游戏接入，在独立窗口打开游戏；已有游戏窗口时可点击 **返回已有窗口**。

如果官方拒绝保存的会话，请在 **账号详情与授权** 中点击 **重新授权** 更新凭据。会话有效性由官方服务器判断；失败时保留账号记录，不会偷偷切换成网页当前登录的账号。

### 备注、详情与移除

- **修改备注**：编辑选中账号的账号备注及区服备注。
- **移除记录**：删除选中账号的本地记录及其保存的登录凭据；不删除游戏角色，不关闭已打开的游戏。
- **账号详情与授权 → 查看账号信息**：查看并复制账号、角色标识，不显示登录凭据。
- **账号详情与授权 → 重新授权**：打开小米官方登录窗口，更新所选账号的凭据，不进入游戏。
- **账号详情与授权 → 清除登录凭据**：只删除所选账号保存的会话，保留备注、角色记录和当前游戏窗口。

账号信息中的 `appAccountId`、`account` 等字段用于标识登录接入账号，不等同于绑定手机号或官网账号密码。

**小米网页登录设置** 单独收起。里面的 **切换小米账号** 会执行小米官方网页退出，再打开登录页；添加账号和使用已保存凭据登录均不会自动执行此操作。

### 返回原窗口与重新登录

脚本会请求同账号的其他窗口回应，辅助判断是否已有活动窗口。需要重新登录时，可以点击 **仍在此窗口登录** 并再次授权；服务器可能使原窗口下线。

浏览器可能限制窗口自动切换焦点。如果没有切到目标窗口，请手动切换浏览器窗口或标签页。

## 面板操作

- **移动**：按住面板标题拖动。
- **隐藏**：点击“隐藏”。
- **恢复**：从油猴菜单选择 **小米服：显示登录面板**。
- **重置位置**：从油猴菜单选择 **小米服：重置面板位置**。

每次重新打开或刷新页面，面板都会恢复为右上角显示、展开的状态；隐藏和拖动只影响当前页面。账号列表会保留。

游戏服务器确认登录成功后，自动隐藏两种登录按钮及入口说明；认证失败或检测到连接断开后重新显示，方便重登。

## 常见问题

### 安装后没有出现面板

确认脚本已启用、当前页面是上面的官网登录页，并检查油猴的网站访问权限。浏览器如要求启用用户脚本权限，可参考 [油猴官方权限说明](https://www.tampermonkey.net/faq.php#Q209)，设置完成后刷新页面。

### 授权窗口或账号窗口没有打开

请允许三国杀官网弹出窗口，再重新操作。

### 授权后停在空白页或 404 页面

回到原游戏窗口，展开 **授权后卡在 404／空白页？**，将授权窗口的完整地址粘贴到输入框，再点击 **继续登录**。该地址包含一次性授权信息，只需粘贴到脚本面板，不要公开发送。

### 提示授权账号与所选账号不一致

选中目标账号，在“账号详情与授权”中点击“重新授权”，使用该账号完成官方登录。核对不通过时，原有凭据不会被其他账号覆盖。

### 提示其他游戏窗口仍有响应，但需要在当前窗口登录

点击 **仍在此窗口登录**，重新完成同一账号的小米官方授权。

### 更新脚本

- 打开或刷新游戏页面时自动检查更新；检查结果缓存六小时，页面长时间打开时也会定时检查。
- 发现新版会直接打开油猴更新页，不弹出额外提示。同一个新版本只自动打开一次，避免多窗口或刷新反复开页；在油猴页面确认更新后，刷新游戏页即可使用新版。
- 面板底部保留 **检查更新** 按钮，点击后立即重新检查。有新版时直接打开更新页；已是最新版或检查失败时，会在面板状态中显示结果。手动检查可再次打开之前关闭的新版更新页。
- 若检查时正在进行登录授权，会等本次流程结束再打开更新页。后台网络失败不会弹提示或影响游戏登录。
- 脚本也配置了油猴的更新地址，油猴自身是否自动安装更新取决于其设置。相关字段见 [油猴官方文档](https://www.tampermonkey.net/documentation.php?locale=en&q=update_url)。

旧版用户需要先通过上面的 **安装／更新脚本** 链接更新；0.2.6 及后续版本支持自动检查。更新记录见 [CHANGELOG.md](CHANGELOG.md)。

### 如何反馈问题

在面板中展开 **运行记录**，最新记录显示在上方，每条带时间和状态标记。出现错误时会自动展开；点击 **仅看异常** 可以集中查看错误与提醒，点击 **显示全部** 恢复完整列表。

**清空记录** 只清空当前页面的记录，不影响账号列表、当前状态或游戏登录。需要反馈时点击 **导出诊断**，到 [Issues](https://github.com/ybl112/sgs-xiaomi-login/issues) 提交浏览器名称、脚本版本、操作步骤和最后一条状态；需要时附上诊断文件。

反馈时请勿公开密码、验证码、完整授权地址或登录凭据；截图如包含个人账号信息，请先遮挡。

## 数据说明

- 账号备注、账号标识、昵称、角色信息和时间等管理记录保存在本机油猴存储中，可通过账号列表移除。
- 每个账号的小米游戏会话作为登录凭据单独保存在本机油猴存储中，用于下次选号登录。脚本不保存小米密码、验证码、浏览器 Cookie、游卡票据或长期游戏启动 token。
- 登录凭据不在账号详情、剪贴板或诊断中展示；“清除登录凭据”删除所选会话，“移除记录”连同会话一起删除。
- 授权码通过油猴存储临时交接，启动参数通过当前窗口的 `sessionStorage` 一次性交接，读取后清理，并校验有效期。
- 必要的登录字段发送至小米和游卡官方接口；脚本没有上传账号管理记录的第三方服务。
- 更新检查从 GitHub 读取公开脚本，不发送账号、角色信息或授权凭据。
- 油猴菜单中的 **小米服：清除临时授权记录** 用于清理临时交接数据；游戏内退出请使用游戏自带功能。

本项目是非官方的浏览器辅助脚本，适用于小米渠道的《三国杀一将成名》。
